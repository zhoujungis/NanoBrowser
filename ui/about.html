这需要先装 Edge 吗？不需要

NanoBrowser 不依赖、也从不启动 Edge 浏览器本体（msedge.exe）。它调用的是 Windows 的系统组件 Microsoft Edge WebView2 运行时——一个可以独立安装、独立卸载、独立更新的运行时， 只提供网页渲染能力，不带浏览器外壳。任务管理器里出现的 msedgewebview2.exe 是这个运行时的宿主进程， 由本机所有使用 WebView2 的应用共享，并不等同于 Edge 浏览器。

卸载 Edge 浏览器，只要运行时还在，NanoBrowser 照常可用；反过来卸载运行时，任何 WebView2 应用都会失效。 选择这条路的原因很直接：应用本体 < 10 MB、内存 < 200 MB。换成自带内核（CEF / Chromium）需要额外 100–300 MB 的磁盘与内存开销，会直接推翻本项目的立项前提。
